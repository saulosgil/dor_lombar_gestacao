
# 🤰 Associação entre ganho de peso na gestação e dor lombar (UNISA)

## 📒 Descrição
- Este repositório consiste na análise exploratória dos dados coletados em um projeto de pesquisa investigando a possível associação entre ganho de peso gestacional e dor lombar.

## 🤖 Technologies Used
- ![R](https://img.shields.io/badge/R-gray?style=flat&logo=r&logoColor=white)


## 🗂️ Dataset

- O dataset foi coletado pela aluna de pós-graduação da Prof. Patricia Colombo (UNISA)


## 📁 Estrutura do repositório

| Arquivo | Descrição |
|---|---|
| `analise_pat_colombo.R` | Script em R com a análise estatística dos dados. |
| `analises_exploratorias.Rmd` | R Markdown com a análise exploratória (código + texto). |
| `analises_exploratorias.md` / `.docx` | Versões renderizadas (Markdown/Word) da análise exploratória. |
| `resultados.docx` | Documento com os resultados consolidados das análises. |
| `analises_exploratorias_files/` | Figuras geradas a partir da análise exploratória. |

## 📑 Referência

Este estudo foi publicado como um estudo transversal (*cross-sectional study*) relacionando o ganho de peso gestacional e a dor lombar no terceiro trimestre da gestação:

> de Oliveira et al. **Correlation Between Gestational Weight Gain and Low Back Pain in the Third Trimester: A Cross-Sectional Study**. *Journal of Pregnancy*, 2026.
> DOI: [10.1155/jp/2063408](https://doi.org/10.1155/jp/2063408)
