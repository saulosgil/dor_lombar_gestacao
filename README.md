
# 🤰 Association Between Gestational Weight Gain and Low Back Pain (UNISA)

## 📒 Description

- This repository contains the exploratory analysis of data collected in a research project investigating the possible association between gestational weight gain and low back pain.

## 🤖 Technologies Used

- ![R](https://img.shields.io/badge/R-gray?style=flat&logo=r&logoColor=white)

## 🗂️ Dataset

- The dataset was collected by a graduate student of Prof. Patricia Colombo (UNISA).

## 📁 Repository structure

| File                                      | Description                                                    |
| ----------------------------------------- | -------------------------------------------------------------- |
| `analise_pat_colombo.R`                 | R script with the statistical analysis of the data.            |
| `analises_exploratorias.Rmd`            | R Markdown with the exploratory analysis (code + text).        |
| `analises_exploratorias.md` / `.docx` | Rendered versions (Markdown/Word) of the exploratory analysis. |
| `resultados.docx`                       | Document with the consolidated results of the analyses.        |
| `analises_exploratorias_files/`         | Figures generated from the exploratory analysis.               |

## 📑 Reference

This study was published as a cross-sectional study examining gestational weight gain and low back pain in the third trimester of pregnancy:

> de Oliveira et al. **Correlation Between Gestational Weight Gain and Low Back Pain in the Third Trimester: A Cross-Sectional Study**. *Journal of Pregnancy*, 2026.
> DOI: [10.1155/jp/2063408](https://doi.org/10.1155/jp/2063408)
